# Здесь команды размещают презентации.

## Минимальное содержание презентации:
- наименование команды;
- постановка задачи;
- роли участников команды;
- используемые вычислительные средства;
- описание модели RAG: используемые эмбеддеры, LLM, pipelene внесения в базу знаний новых знаний, pipeline отработки запроса;
- основные результаты исследований для 50 и для 1000 запросов (опционально - для 10000): метрики оценки выдачи чанков HR@1, 3, 5; метрики оценки качество ответа AnswerRight@1, 3, 5;
- временные оценки обработки 1 запроса;
- анализ результатов (случаи, когда работает поиск, когда не работает, когда ответ не находится);
- выводы.
