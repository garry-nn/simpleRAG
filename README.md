# Результаты исследований RAG-систем
## объект исследования
различные модификации RAG-систем 

## предмет исследования
Качество работы различных модификаций RAG-систем, работающими на различных доменных базах знаний, отличающихся:
- используемыми эмбеддерами,
- используемыми LLM для генерации ответа,
- способом нарезками на чанки текстов,
- способами предобработки исходных текстов (таблиц, картинок).
